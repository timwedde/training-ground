# AGENTS.md

- Commit as you go.
- Do not use the README.md file as a development log. It should contain only a brief overview of the app and how to run it, as well as explain its most important features.
- Keep tests minimal. Only add tests for important, complex logic that may drift over time, keep the total number of tests low. Never add tests for trivial things.
- Keep code concise, readable and modular, clean up duplication and inefficiencies in systems you touch when you come across them.
